Inside the operating system

Five systems. Clear roles.

Nucleo divides key tasks among specialized components instead of placing every responsibility in one undifferentiated layer.

01 / CONNECT

Protocol kernel

Coordinates the wallet's interactions with external devices through defined communication interfaces.

02 / PROTECT

Cryptographic kernel

Provides a secure, time-deterministic environment for sensitive cryptographic operations.

03 / EXECUTE

Application VM

Runs applications in an execution environment built around an optimized subset of JavaScript.

04 / UNDERSTAND

Blockchain modules

Dedicated kernels provide specialized logic for EVM, Bitcoin and Tron workflows.

05 / STORE

Storage subsystems

Separate components manage system settings and encrypted data storage.

Architecture by intent

Built to be understood and extended.

Nucleo is written in C++ and organized as modular components. The architecture is designed to make changes focused and rigorous review practical.

Execution model

A dedicated environment for one task at a time.

The single-tasking design keeps the operating system focused on the work a wallet needs to perform, with sensitive functions assigned to dedicated components.

Modular design

Specialized systems, one foundation.

Protocol handling, cryptography, applications, chain logic and storage remain distinct while working together as a coherent operating system.

Current connectivity

Defined interfaces to the outside.

Nucleo communicates with host software through current wired interfaces and a JSON-RPC-based protocol. WebHID enables interaction from a compatible browser.

01 / INTERFACESerial
02 / INTERFACEUSB HID
03 / PROTOCOLJSON-RPC
04 / BROWSERWebHID

Availability depends on the device and integration. These are software architecture interfaces, not a promise that every hardware variant exposes every connection.

Development roadmap

A foundation designed to grow.

The architecture leaves room for additional systems as future devices and applications evolve.

  1. 01
    Graphics & interface VM

    Support for future devices with graphical displays.

  2. 02
    Power management

    Battery operation, charging and energy efficiency.

  3. 03
    Network & HID systems

    Additional compatibility and connectivity options.

  4. 04
    Peripheral controllers

    Potential support for external memory, cameras and audio.

Roadmap items—including wireless connectivity—are not presented as features of the current TriPylon Touch hardware.
