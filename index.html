The operating system

Meet TriPylon Nucleo.

A specialized, single-tasking operating system at the heart of TriPylon wallets. Its modular C++ architecture separates communication, cryptography, applications, blockchain logic and storage into focused components.

Built to evolve
01 / CONNECT

Protocol kernel

Coordinates communication with external devices through defined interfaces.

02 / PROTECT

Cryptographic kernel

Runs sensitive operations in a time-deterministic environment.

03 / EXECUTE

Application VM

Runs wallet applications using an optimized subset of JavaScript.

04 / EXTEND

Chain & storage modules

Dedicated logic for EVM, Bitcoin and Tron, plus separate settings and encrypted data storage.

Current interfaces include Serial and USB HID, with WebHID for browser interaction. Graphics, power management and additional peripherals belong to the development roadmap.

First-generation hardware

TriPylon Touch.
Built in layers.

The first TriPylon Touch combines hardware safeguards with Nucleo's software architecture. These hardware details describe the first generation; future devices may use a different configuration.

Verified startup

Secure Boot is designed to run only signed firmware on the device.

Encrypted storage

Flash encryption protects data stored in device memory.

Locked debug access

One-time hardware settings can permanently disable debugging interfaces.

Fast cryptography

Hardware acceleration supports common cryptographic operations.

Browser connection

USB HID enables direct browser interaction through WebHID.

Room to grow

Processing and memory capacity provide headroom for Nucleo's VM and richer future interfaces.

Wireless capabilities and graphical interfaces discussed in the architecture roadmap are not presented here as features of the current Touch hardware.
